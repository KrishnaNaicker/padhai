# Padhai

This repository is an Agent Skill that makes exam-ready university notes from a syllabus.

When a user asks for exam notes, unit notes, answers to previous-year questions (PYQs) or a question bank for a syllabus,
read `skills/padhai/SKILL.md` and follow it exactly. Its `references/` folder holds the detailed rules and its
`scripts/` folder the build tools. A complete example unit is in `skills/padhai/examples/ml-unit3-classification/`.
