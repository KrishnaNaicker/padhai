Core formulas
  • Linear classifier: $\hat y=\operatorname{sign}(w\cdot x+b)$; distance $=|w\cdot x+b|/\lVert w\rVert$
  • Accuracy $=\frac{TP+TN}{\text{Total}}$ · Error rate = 1 − accuracy
  • Precision $=\frac{TP}{TP+FP}$ · Recall $=\frac{TP}{TP+FN}$
  • $F_1=\frac{2PR}{P+R}=\frac{2TP}{2TP+FP+FN}$ · Specificity $=\frac{TN}{TN+FP}$
  • Multiclass: $FP_k$ = column total − $TP_k$; $FN_k$ = row total − $TP_k$
  • OvA: K models · OvO: $K(K-1)/2$ models
  • Euclidean $d=\sqrt{\sum(x_i-y_i)^2}$ · Manhattan $\sum|x_i-y_i|$
  • SVM: $\min\frac12\lVert w\rVert^2$ s.t. $y_i(w\cdot x_i+b)\ge1$; margin $=2/\lVert w\rVert$
  • Soft: $\min\frac12\lVert w\rVert^2+C\sum\xi_i$, $y_i(w\cdot x_i+b)\ge1-\xi_i$
  • Poly $(\gamma x\cdot z+r)^d$ · RBF $e^{-\gamma\lVert x-z\rVert^2}$ · Gaussian $e^{-\lVert x-z\rVert^2/2\sigma^2}$ · Sigmoid $\tanh(\gamma x\cdot z+r)$
  • $SSE=\sum(y_i-\hat y_i)^2$ · $MSE=SSE/n$ · $RMSE=\sqrt{MSE}$
  • Bayesian: posterior ∝ likelihood × prior; $S_N^{-1}=\alpha I+X^TX/\sigma^2$
One-liners examiners love
  • Classification = supervised learning with a discrete output label.
  • Binary: 2 classes, 1 boundary, sigmoid. Multiclass: K classes, softmax or OvA / OvO.
  • Imbalanced data: "accuracy lies". Use recall, F1, SMOTE, class weights.
  • Precision = trust in a positive prediction; Recall = fraction of positives caught.
  • FP = Type I (false alarm); FN = Type II (miss). In cancer screening, FN is worse.
  • Macro average treats classes equally; micro average equals accuracy for single-label data.
  • KNN is a lazy, non-parametric, instance-based learner; always scale features.
  • Small K overfits, large K underfits; choose an odd K by cross-validation.
  • SVM keeps only the support vectors; all other points could be deleted.
  • Hard margin = soft margin with C → ∞. Large C: narrow margin; small C: wide margin.
  • Kernel trick: $K(x,z)=\phi(x)\cdot\phi(z)$ without computing φ. Gaussian = RBF with $\gamma=1/2\sigma^2$.
  • Bayesian regression gives uncertainty; its MAP estimate equals Ridge regression.
