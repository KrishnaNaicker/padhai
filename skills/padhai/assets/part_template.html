Differentiate between preemptive and non-preemptive scheduling.

Definitions

  • Preemptive scheduling: the OS can take the CPU away from a running process (on a higher-priority arrival or time-slice expiry).
  • Non-preemptive scheduling: a process keeps the CPU until it finishes or blocks for I/O.

Difference

BasisPreemptiveNon-preemptive
CPU releaseForced by the OSVoluntary (finish or I/O)
Response timeLow; good for interactive systemsCan be high
OverheadContext switches add overheadMinimal
StarvationPossible for low-priority processesPossible behind long jobs
ExamplesRound Robin, SRTF, preemptive priorityFCFS, SJF, non-preemptive priority
New→Ready→Running→Terminated

Running → Ready happens only in preemptive scheduling

Preemptive = the OS can interrupt; non-preemptive = the process decides when to leave.
Preemptive scheduling gives better response time at the cost of context switches; non-preemptive scheduling is simpler but can make short jobs wait.
Consider processes P1–P4 with arrival times 0, 1, 2, 3 ms and burst times 5, 3, 8, 6 ms. Draw the Gantt chart for FCFS and calculate the average waiting time and average turnaround time.

Formulas

Turnaround and waiting time $$TAT_i = CT_i - AT_i \qquad WT_i = TAT_i - BT_i$$
CT = completion time, AT = arrival time, BT = burst time.

Gantt Chart

Calculation

  1. Schedule in arrival order: P1 0–5, P2 5–8, P3 8–16, P4 16–22.
  2. Turnaround: P1 = 5 − 0 = 5, P2 = 8 − 1 = 7, P3 = 16 − 2 = 14, P4 = 22 − 3 = 19.
  3. Waiting: P1 = 0, P2 = 4, P3 = 6, P4 = 13.
Result $$\overline{WT}=\frac{0+4+6+13}{4}=5.75\text{ ms}\qquad \overline{TAT}=\frac{5+7+14+19}{4}=11.25\text{ ms}$$
Always draw the Gantt chart with times marked under every boundary; it carries marks on its own.
Under FCFS the average waiting time is 5.75 ms and the average turnaround time is 11.25 ms; the long burst of P3 makes P4 wait 13 ms (convoy effect).
Core formulas
  • $TAT = CT - AT$ · $WT = TAT - BT$
